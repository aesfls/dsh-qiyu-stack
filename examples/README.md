# examples/

样板角色放这里，**默认不安装**，只是让人看看「能长成什么样」。

暂时是空的。

以后会把「作者自己那套」整理一份放进来——去掉所有隐私（聊天记录、令牌、那封私人信件），
只保留结构和写法，比如：

```
examples/qianyu/
├── AGENTS.md          人格长什么样（行为 + 性格都写满的那种）
├── schedule.json      三个时段怎么排
├── letters/           写给她的信（示例，内容换成假的）
└── README.md          为什么这么写
```

在它出现之前，先用 `templates/blank` 起步，性格那几行自己填。
