# 更新记录 · dsh-qq-guard

## 0.3.0（2026-10-25）

随栖语栈一起发布。这一版主要是**把"作者自己机器上的东西"从默认值里拿掉**，
外加把默认档位调成"先只看不拦"：

- 默认 `目标会话` 改成空 —— **留空 = 管所有会话**（只对"外头来的那一轮"动手，不误伤界面里的对话）；
  `判定()` 与挂监听两处口径一致（以前留空等于整个护栏不工作）
- "她的家"不再写死盘符：从 `~/.dsh/qiyu/character.json` 的「路径」反推；
  人格 / 日记只在文件真的存在时才进快照清单
- 快照默认清单只留 `~/.dsh` 下的配置，不再包含作者机器上的私人文件名
- 提示规则里的称呼从作者家的叫法改成「主人」
- 默认 `模式: dry`（只记账不拦）——**新装的人先看一天日志再切 `enforce`**
- 群白名单默认仍是保守的 5 项（`read` / `glob` / `grep` / `qq_group_say` / `qq_sticker`），
  要放开语音、画图、撤回、搜索就往配置的 `白名单` 里加（热生效）
- 注释里不再引用作者本机的维护目录
